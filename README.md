# ✨ Quote Generator

A modern and interactive Quote Generator web application built using Python Flask, MySQL, HTML, CSS, and JavaScript.

## 📌 About the Project

Quote Generator is a web application that generates random inspirational quotes using an API. Users can explore quotes, save their quote history, manage favourites, search saved quotes, copy quotes, and download them.

## 🚀 Features

- Generate random inspirational quotes.
- Display quote and author information.
- Save generated quotes in MySQL.
- View previously generated quotes.
- Add quotes to favourites.
- Remove quotes from favourites.
- Delete quotes from history.
- Search saved quotes.
- Copy quotes to clipboard.
- Download quotes.
- Modern gradient-themed user interface.

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **API:** DummyJSON Quotes API
- **Tools:** Visual Studio Code, MySQL Workbench, Git, GitHub

## ⚙️ Installation and Setup

1. Clone the repository:

   `git clone https://github.com/Shravani-cpu/Quote-Generator.git`

2. Open the project folder:

   `cd Quote-Generator`

3. Create a virtual environment:

   `python -m venv venv`

4. Activate the virtual environment on Windows:

   `venv\Scripts\activate`

5. Install dependencies:

   `pip install -r requirements.txt`

6. Configure your MySQL database and credentials using environment variables.

7. Run the application:

   `python app.py`

8. Open your browser and visit:

   `http://127.0.0.1:5000`

## 🗄️ Database

The application uses MySQL to store generated quotes, authors, timestamps, and favourite status.
